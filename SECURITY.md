# Security

## Reporting a vulnerability

If you believe you have found a security issue in LYFTIUM (the product or this repository), please report it through the [LYFTIUM portal](https://app.lyftium.com). Do not open a public GitHub issue for sensitive reports.

## API keys

- Send keys only in the `X-Api-Key` header.
- Do not put keys in URLs, query strings, client-side bundles, or public repositories.
- Rotate a key immediately from the portal if it may have been exposed.

## Scope

This repository is public documentation and marketing for LYFTIUM's Ethereum Mainnet JSON-RPC endpoint. Product support and account issues: [https://app.lyftium.com](https://app.lyftium.com).
